# Statistical typesetting rule catalogue

This catalogue is the authoritative, shared rule collection for the
`latex-typesetting` skill and the LaTeX chapter in the book. Rules
record the author's stated preferences, not universal requirements. A manuscript
or journal may call for another choice. Source references point to the repository
as it stands; `ch-tools.qmd` is the primary source and
`lecturesSp23/Note_02_LaTeX.Rmd` is the teaching-note counterpart. The later
`slides/latex.qmd` supplies illustrative examples, not new author rationales.

**Rationale status:** “Source-stated” means the cited manuscript gives the
rationale shown. “Author input needed” means no rationale was stated. A sentence
marked **Proposed rationale for author review** is an interpretation, not an
attributed author rationale. Verification can combine source inspection,
build logs, and visual review; a syntactic check alone does not establish a
style judgment.

## Equations

| ID / kind | Source | Preferred practice | Justification / status | Before → after | Exceptions | Verification |
|---|---|---|---|---|---|---|
| EQ-01 · style | `ch-tools.qmd`, Math equations | Punctuate displayed equations as parts of their sentences. | **Source-stated:** equations are part of sentences. | `... is given by` `\[x=1\]` → `... is given by` `\[x=1.\]` | Punctuation follows sentence structure and journal conventions. | Read surrounding prose and inspect rendered punctuation. |
| EQ-02 · style | same | Add source whitespace around operators/symbols where it improves readability. | **Source-stated:** better readability in sources. | `x=y+z` → `x = y + z` | Compact notation may be conventional or clearer in context. | Inspect source; use judgment. |
| EQ-03 · style | same | Avoid beginning a sentence with a math symbol; rephrase. | **Author input needed.** **Proposed rationale for author review:** a verbal lead-in can make the sentence easier to parse. | `$X$ is normal.` → `The variable $X$ is normally distributed.` | Notation-led statements may be appropriate in lists or formal derivations. | Read sentence in context. |
| EQ-04 · style | same | Avoid `\frac` in inline math; use a compact slash form or display math. | **Author input needed.** **Proposed rationale for author review:** slash forms tend to preserve line rhythm. | `$\frac{a}{b}$` → `$a/b$` | Use a fraction when it is clearer, conventional, or required by a journal. | Inspect source and line layout. |
| EQ-05 · style | same | Do not split one inline math expression across source lines. | **Author input needed.** **Proposed rationale for author review:** keeping the expression together helps source editing and review. | `$a +` newline `b$` → `$a + b$` | Long source lines may be unavoidable; do not change rendered mathematics just to satisfy a source-line preference. | Inspect source boundaries. |
| EQ-06 · style | same | Number/label only equations that are referenced. | **Author input needed.** **Proposed rationale for author review:** numbering only used equations reduces visual clutter. | `\begin{equation}x=1\label{eq:x}\end{equation}` (never cited) → unnumbered display | Journal templates may number every display. | Search label references; inspect class numbering policy. |
| EQ-07 · style | same | Refer to numbered equations with `\eqref{...}` rather than ` (\ref{...})`. | **Author input needed.** **Proposed rationale for author review:** `\eqref` supplies conventional equation parentheses consistently. | `Equation (\ref{eq:x})` → `Equation~\eqref{eq:x}` | Frontends or templates may provide a different reference command. | Inspect macros and compiled output. |
| EQ-08 · style | same | Keep notation fonts consistent, e.g. variables in math and acronyms in text/roman style consistently. | **Source-stated:** same notations should have consistent fonts. | `n` then `$n$` → `$n$` throughout | Follow established notation and journal macros. | Search notation variants and inspect context. |
| EQ-09 · style | same | Size parentheses appropriately. | **Author input needed.** **Proposed rationale for author review:** delimiters should visibly enclose the expression without looking cramped or oversized. | `(\sum_i x_i)` → `\left(\sum_i x_i\right)` where warranted | Automatic sizing can be too large; use fixed sizes when better. | Inspect rendered equation. |
| EQ-10 · style | same | For nested delimiters, prefer `[\{( ... )\}]` unless journal specifies otherwise. | **Author input needed.** **Proposed rationale for author review:** a consistent nesting order makes delimiter scope easier to scan. | `(( [x] ))` → `[\{(x)\}]` | Journal or mathematical convention takes precedence. | Inspect source and rendered grouping. |
| EQ-11 · style | same | Use predefined operators such as `\exp`, `\Pr`, `\min` rather than italic text. | **Author input needed.** **Proposed rationale for author review:** operator functions are distinguished from variables and rendered consistently. | `$exp(x), P(A)$` → `$\exp(x), \Pr(A)$` | Preserve a field's established notation when it is intentional. | Inspect math semantics and output. |
| EQ-12 · style | same | Use `\allowdisplaybreaks`/the established equivalent to permit page breaks in long aligned displays. | **Source-stated:** it allows page breaks in aligned equations. | No display-break setting → `\allowdisplaybreaks` in preamble (if appropriate) | Do not add it if the class/template disallows it or no long displays need breaks; note source variants use singular/plural command spelling. | Check defined package/class command and PDF page breaks. |
| EQ-13 · style | same | Use `\dd` for the differentiation operator when the project defines it (the source associates it with `physics`). | **Author input needed.** **Proposed rationale for author review:** a dedicated macro can keep differential notation consistent. | `dx` → `\dd x` | Do not introduce an undefined or conflicting macro; journal macros take precedence. | Inspect preamble/package and compiled symbol. |
| EQ-14 · style | same | Break long equations at meaningful mathematical points, not arbitrarily; use readable source lines and suitable alignment. | **Source-stated:** shorter lines and sufficient spaces make source more readable; alignment should be appropriate. | One long arbitrary line → aligned continuation at `=` or another semantic relation | Preserve a single line when it is clearer and fits. | Inspect source and rendered line breaks. |

## Tables

| ID / kind | Source | Preferred practice | Justification / status | Before → after | Exceptions | Verification |
|---|---|---|---|---|---|---|
| TB-01 · style | `ch-tools.qmd`, Tables | Consider generating table source from data rather than hand-maintaining it. | **Author input needed.** **Proposed rationale for author review:** generated tables can be regenerated consistently from their data. | Manually copied values → generated table source (e.g. `xtable`) | Hand-authored tables are appropriate when the layout is bespoke or data generation is unsuitable. | Trace source/data workflow; check reproducibility. |
| TB-02 · style | same | Use a self-contained, informative caption. | **Author input needed.** **Proposed rationale for author review:** readers should be able to understand the table's purpose and context from its caption. | `\caption{Results}` → `\caption{Bias and RMSE by method at each sample size.}` | Keep detail concise; follow journal caption limits. | Read caption with table alone. |
| TB-03 · style | same | Put table captions above tables unless journal instructions differ. | **Author input needed.** **Proposed rationale for author review:** this establishes a predictable reading order. | `tabular ... \caption{...}` → `\caption{...} ... tabular` | Journal instructions or class templates take precedence. | Inspect source order and PDF. |
| TB-04 · style | same | Prefer `tbp` float placement and avoid `[h]`. | **Author input needed.** **Proposed rationale for author review:** flexible placement gives TeX room to produce better page composition. | `\begin{table}[h]` → `\begin{table}[tbp]` | Templates, accessibility, or a specific layout need may justify another placement. | Inspect float source and resulting pages. |
| TB-05 · style | same | Avoid vertical rules. | **Author input needed.** **Proposed rationale for author review:** fewer grid lines can reduce visual noise. | `|l|r|` → `lr` | A journal-mandated format takes precedence. | Inspect table source and PDF. |
| TB-06 · style | same | Typeset negative signs in math mode. | **Author input needed.** **Proposed rationale for author review:** a mathematical minus sign is typographically distinct from a text hyphen. | `-0.2` → `$-0.2$` | Use a column-aware numeric alignment tool if it preserves math minus rendering. | Inspect source and glyph in PDF. |
| TB-07 · style | same | Prefer `booktabs` rules (`\toprule`, `\midrule`, `\bottomrule`). | **Author input needed.** **Proposed rationale for author review:** a small hierarchy of rules clarifies table structure. | `\hline` after every row → three-level `booktabs` rules | Follow journal requirements; do not mix incompatible rule styles. | Inspect package availability, source, and PDF. |
| TB-08 · style | same | Use `\cmidrule` to express grouped column hierarchy. | **Author input needed.** **Proposed rationale for author review:** partial rules show which grouped headings span which columns. | Full-width rule under every group → `\cmidrule(lr){2-3}` | Use only when the table has meaningful grouped columns; source variants mention `multirow` as another optional tool. | Check group spans and rendered alignment. |
| TB-09 · style | same | Do not shrink table font as the first fit strategy; revise layout instead. | **Source-stated:** change table layout to fit instead of resizing it. | `\small` to force width → reorganize columns/labels | Journal may explicitly require a size adjustment; an intentional small table can be appropriate. | Inspect font size and legibility at normal zoom/print. |
| TB-10 · style | same | Right-align decimal values. | **Author input needed.** **Proposed rationale for author review:** decimal alignment makes magnitudes easier to compare. | centered `0.2`, `12.35` → decimal-aligned column | Follow journal format or use suitable `siunitx`/column macro. | Inspect column alignment in PDF. |
| TB-11 · style | same | Keep precision consistent within a column/row of comparable measurements. | **Author input needed.** **Proposed rationale for author review:** consistent precision helps comparison. | `0.2`, `0.1534` → consistent meaningful precision | Preserve precision required for uncertainty or scientific interpretation. | Check values against the underlying data and table purpose. |
| TB-12 · style | same | Avoid many leading zeros in decimals; consider scientific notation or a clearly explained scale. | **Author input needed.** **Proposed rationale for author review:** alternate scaling can make very small magnitudes easier to compare. | `0.000045` → `4.5\times 10^{-5}` or a stated scaling | Keep the leading zero if journal style, readability, or interpretation benefits; never use an ambiguous scale. | Check caption/header scale and numerical meaning. |

## Figures

| ID / kind | Source | Preferred practice | Justification / status | Before → after | Exceptions | Verification |
|---|---|---|---|---|---|---|
| FG-01 · style | `ch-tools.qmd`, Figures | Prefer vector graphs over raster graphs, except when raster is necessary (e.g. screenshots). | **Source-stated:** vector graphics can be improved easily and remain suitable for editing. | Low-resolution plot image → PDF/vector plot | Photographs, screenshots, raster-only data, or journal constraints. | Inspect file type, resolution, and zoomed PDF. |
| FG-02 · style | same | Save the code that generates figures. | **Source-stated:** figures can then be improved easily. | Image only → image plus generation source | External/licensed assets or unavailable legacy source; report limitation. | Locate source and determine whether output is reproducible. |
| FG-03 · style | same | Use flexible `tbp` placement and avoid `[h]`. | **Author input needed.** **Proposed rationale for author review:** flexible placement gives TeX room to compose pages. | `[h]` → `[tbp]` | Follow required template or a justified layout need. | Inspect source and PDF float placement. |
| FG-04 · technical/style | same | Use `graphicx` for `\includegraphics` when required by the build/template. | **Author input needed.** **Proposed rationale for author review:** the package provides the graphics inclusion command used in the examples. | Missing package with `\includegraphics` → load package or rely on class that loads it | Do not add redundant package loads; frontend may manage inclusion. | Inspect class/preamble and compile. |
| FG-05 · style | same | Use a self-contained, informative caption. | **Author input needed.** **Proposed rationale for author review:** readers can interpret the figure without hunting for essential context in the prose. | `\caption{Plot}` → state quantity, groups, and conditions | Keep caption concise and avoid repeating a full results section. | Read caption independently; inspect rendered PDF. |
| FG-06 · style | same | Put figure captions below figures unless journal instructions differ. | **Author input needed.** **Proposed rationale for author review:** this gives a predictable figure-then-caption reading order. | `\caption{...}\includegraphics...` → `\includegraphics...\caption{...}` | Journal/template takes precedence. | Inspect source and PDF. |
| FG-07 · style | same | Distinguish line groups by line pattern, not color alone; use different point symbols similarly. | **Source-stated:** readers can still tell groups apart when printed black and white. | Red/blue solid lines → solid/dashed lines (optionally color too) | Color-only may be acceptable where grayscale reproduction is irrelevant and accessibility is otherwise addressed. | Inspect grayscale/monochrome rendering. |
| FG-08 · style | same | Use colorblind-friendly colors, especially avoid relying on red/green contrast. | **Author input needed.** **Proposed rationale for author review:** readers with color-vision differences can distinguish data. | red vs green only → accessible palette plus redundant encoding | Respect journal palette or categorical meanings; retain non-color cues. | Check with palette preview or color-vision simulator and grayscale. |
| FG-09 · style | same | Preserve necessary aspect ratio (e.g. maps, court diagrams, P-P plots). | **Source-stated:** listed as a case where the correct ratio matters. | Distorted map → proportional resize | Intentional coordinate scaling may be scientifically meaningful when explained. | Compare geometry with source dimensions and inspect PDF. |
| FG-10 · style | same | Remove extra margins around the graphic. | **Author input needed.** **Proposed rationale for author review:** excess whitespace wastes layout area and can make the plot seem small. | Large blank border → cropped graphic with labels intact | Keep necessary labels, uncertainty bands, or breathing room. | Inspect full-page and close-up PDF. |
| FG-11 · style | same | Preserve aspect ratio while resizing, e.g. set width without conflicting height. | **Source-stated:** “Keep the ratio when resizing.” | Forced width and height distorting plot → `width=\textwidth` with natural ratio | A deliberately changed aspect ratio is acceptable when part of the data encoding and clearly conveyed. | Compare source and output proportions. |
| FG-12 · style | same | Name figure files descriptively. | **Author input needed.** **Proposed rationale for author review:** meaningful filenames help maintain the source and connect plots to content. | `fig2.pdf` → `rmse-by-sample-size.pdf` | Preserve externally mandated filenames and references. | Inspect path/name and all inclusion references. |

## Source notes and boundaries

- The book source's equation guidance says `\allowdisplaybreak`; its teaching
  counterpart and newer slides say `\allowdisplaybreaks`. Preserve an existing
  macro/package convention and verify the command actually defined before
  suggesting either spelling.
- The book mentions `\cmidrule()` while the lecture note says `\cmidrule{}`;
  the command in use is `\cmidrule{<range>}` (with optional trimming
  arguments), but make no edit until the actual `booktabs` syntax and intent are
  clear. Treat `multirow` as optional teaching-note guidance, not a rule in the
  primary chapter.
- The two BibTeX sources differ on capitalization (title style vs. title
  capitalization of notional words; ending punctuation guidance appears only in
  the lecture). Do not silently reconcile conflicting guidance; ask the author
  or journal instructions when this affects an edit.
- The catalogue covers the requested initial scope only. It does not authorize
  scientific-content review or substantive prose revision.
